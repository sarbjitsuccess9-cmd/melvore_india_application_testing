## Media & Asset Origin Resolution Rules
- **Catalog / Storefront Media (`uploads/...`)**: Resolved against `https://melvore.co.in` (`DtoMappers.resolveMediaUrl`).
- **Design System Kit SVGs (`/design-system/assets/svg/...`)**: Resolved against `asset_base_url` from `api/design/manifest.php`, falling back to `SecureSessionStore.getApiBaseUrl()` (`https://app.melvore.co.in`). Animated SMIL SVGs render via `AnimatedSvg` WebView with static Coil fallback when reduced motion is enabled or WebView fails.
